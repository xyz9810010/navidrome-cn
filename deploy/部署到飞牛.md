# Navidrome-cn 部署到飞牛（fnOS）

本文档把当前仓库（含 100% 简体中文汉化）打包成 Docker 镜像并部署到飞牛 NAS。

## 一、你需要准备的

1. 一台飞牛（fnOS）NAS，且能联网（首次构建需要下载依赖）。
2. 飞牛已安装 **Docker** 应用（应用中心 → 搜索“Docker”安装）。
3. 本仓库一份（可直接在飞牛上用 git 克隆，或上传压缩包）。

## 二、核心问题：为什么不能直接用官方镜像？

官方 `deluan/navidrome` 镜像不含本仓库的 100% 汉化改动，所以必须**自己构建一个自定义镜像**。
下面给出三种构建方式，任选其一。

## 方式 A：在飞牛上通过 SSH 构建（推荐，全程在 NAS 上完成）

### 1. 打开飞牛 SSH
- 飞牛 Web 后台 → **设置 → 终端（SSH）**，开启 SSH。
- 用电脑终端登录：`ssh 用户名@飞牛IP`（默认端口 22）。

### 2. 获取源码并构建

```bash
# 进入一个可写目录
mkdir -p /vol1/1000/docker && cd /vol1/1000/docker

# 克隆本仓库
git clone https://github.com/xyz9810010/navidrome-cn.git
cd navidrome-cn

# 构建镜像（单架构，飞牛 x86_64 即可）
docker build -t navidrome-cn:latest .
```

> 首次构建约需 5~15 分钟（要下载 Go 1.26 和 Node 依赖）。若飞牛是 ARM 架构（如一些低功耗机型），
> 用 `docker buildx build --platform linux/arm64 -t navidrome-cn:latest .`。

### 3. 用 Compose 启动

```bash
cd /vol1/1000/docker/navidrome-cn/deploy
# 先编辑 docker-compose.yml，把 /vol1/1000/music 改成你的音乐目录
vi docker-compose.yml

docker compose up -d
```

## 方式 B：在别的机器上构建，导出镜像再导入飞牛

适合飞牛不方便构建、或想在开发机构建的场景。

```bash
# 在装有 Docker 的机器上（项目根目录）
docker build -t navidrome-cn:latest .
docker save navidrome-cn:latest | gzip > navidrome-cn.tar.gz
```

把 `navidrome-cn.tar.gz` 传到飞牛后：

```bash
docker load < navidrome-cn.tar.gz
```

（也可在飞牛 Docker 应用 → 镜像 → 导入，选择该 tar 文件。）

## 方式 C：推送到 Docker Hub 后让飞牛拉取

```bash
docker build -t xyz9810010/navidrome-cn:latest .
docker push xyz9810010/navidrome-cn:latest
```

然后在飞牛 Docker 应用 → 镜像 → 拉取 `xyz9810010/navidrome-cn:latest`，
并把 `deploy/docker-compose.yml` 里的 `image` 改成这个镜像名。

## 三、在飞牛 Docker 图形界面部署（不用命令行）

1. 打开飞牛 **Docker** 应用。
2. **镜像** 页：先构建/导入/拉取好 `navidrome-cn:latest`。
3. **项目（Compose）** 页：新建项目，粘贴 `deploy/docker-compose.yml` 内容，
   或直接上传该文件；把挂载路径改成你的真实目录。
4. 启动后，在 **容器** 页确认 `navidrome-cn` 状态为运行中。

## 四、首次登录

1. 浏览器访问 `http://飞牛IP:4533`。
2. 首次使用会提示创建管理员账号（界面已是中文）。
3. 之后在 **设置 → 个性化 → 语言** 里默认就是 **简体中文**（`ND_DEFAULTLANGUAGE=zh-Hans` 已配置）。

## 五、常用环境变量（可选）

| 变量 | 说明 |
| --- | --- |
| `ND_DEFAULTLANGUAGE` | 默认语言，已设为 `zh-Hans` |
| `ND_DEFAULTTHEME` | 默认主题 |
| `ND_SCANSCHEDULER` | 自动扫描周期，默认 `1h` |
| `ND_SESSIONTIMEOUT` | 登录保持时长 |
| `ND_ENABLETRANSCODINGCONFIG` | 设为 `true` 才能在网页改转码（有安全风险，谨慎） |
